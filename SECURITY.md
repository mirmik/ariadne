# Security policy

## Supported versions

Ariadne is experimental. Security fixes are provided only for the latest
release and the default branch.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a
vulnerability** form in the Security tab of this repository. Do not open a
public issue for an undisclosed vulnerability.

Include the affected version, deployment topology, reproduction steps and the
expected security impact. Reports are acknowledged as soon as practical; no
fixed response or remediation deadline is currently guaranteed.
